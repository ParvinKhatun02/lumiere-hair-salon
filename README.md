
# LUMIÈRE – Hair Salon Website

A modern, elegant, and responsive hair salon website built with React and Tailwind CSS. LUMIÈRE provides a beautiful online experience where customers can explore salon services, meet professional stylists, view the gallery, and book appointments.

**Get Hair Style, You Deserve.**

## 🌐 Live Demo

[Visit LUMIÈRE Hair Salon](https://lumiere-hair-salon.vercel.app/)

## ✨ Features

- **Home Page:** Elegant hero section with responsive design and salon introduction.
- **About Us:** Information about the salon, its vision, and services.
- **Our Services:** Explore available hair treatments and styling services.
- **Our Team:** Meet the salon's professional stylists.
- **Gallery:** Browse salon-related images and styles.
- **Appointment Booking:** User-friendly appointment booking interface.
- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **Modern UI:** Clean layout, elegant typography, and a consistent color palette.
- **Navigation:** Easy navigation between different pages.

## 🛠️ Technologies Used

- **React.js** – Building reusable UI components.
- **JavaScript (ES6+)** – Application functionality.
- **Tailwind CSS** – Responsive styling and layouts.
- **React Router DOM** – Client-side navigation.
- **Lucide React** – Icons.
- **React Day Picker** – Date selection for appointments.
- **Vite** – Development server and build tool.
- **Git & GitHub** – Version control and project hosting.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/ParvinKhatun02/lumiere-hair-salon.git
```

### 2. Navigate to the Project Directory

```bash
cd lumiere-hair-salon
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the website.
